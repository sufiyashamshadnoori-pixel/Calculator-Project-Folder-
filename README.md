# Simple Calculator

A basic calculator built using **HTML**, **CSS**, and **JavaScript**.  
It performs standard arithmetic operations and updates the display in real time.  
This project uses the Math.js library to evaluate expressions.

---

## 📌 Features

- Clean and simple UI  
- Real-time display updates  
- Supports:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- **DEL** button → deletes last character  
- **C** button → clears the entire screen  
- Fully responsive layout  
- Uses **Math.js** for expression evaluation

---

## 🖥️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- [Math.js CDN](https://mathjs.org/)
